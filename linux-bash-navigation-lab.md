# Linux Bash Navigation Lab

This lab demonstrates my practical experience navigating and exploring the Linux file system using the Bash shell.

## Skills Demonstrated

* Navigating the Linux file system using Bash commands
* Using `pwd`, `ls`, and `cd` to explore directories
* Reading and previewing file contents using `cat` and `head`
* Working with nested directories and file paths

## Lab Example

During this lab exercise, I performed the following tasks:

### 1. Navigated to the Analyst's Home Directory

```bash
cd /home/analyst
```

### 2. Listed Files and Directories

```bash
ls
```

This allowed me to view the files and subdirectories within the analyst's home directory.

### 3. Explored Different Directories

I navigated through the `reports/users` directory and then moved to the `logs` directory.

```bash
cd reports/users
ls

cd ../../logs
ls
```

### 4. Read and Previewed File Contents

I used `cat` to display the contents of a file and `head` to preview the beginning of the file.

```bash
cat Q1_added_users.txt
head Q1_added_users.txt
```

## Summary

This lab helped me practice essential Linux command-line skills used to navigate directories, locate files, and inspect file contents.

These Bash fundamentals are important for cybersecurity work, particularly when working with Linux systems, logs, directories, and security-related files.
